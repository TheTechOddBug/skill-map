# New page

Creates a blank page so you can start writing, then hand it to
/content-editor to fill in.

1. Copy the shared template

   Write a new `public/<name>.html` with the `<!doctype html>` shell, the
   stylesheet link, and an empty `<main>`.

2. Link it from Home

   Add the new page to the home nav so it is reachable.
