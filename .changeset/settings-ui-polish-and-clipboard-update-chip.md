UI polish across Settings, topbar, list / graph empty states, the Matrix theme, and the list-view column order. Pure `ui/` change, no spec / kernel / CLI verbs touched; the patch bump on `@skill-map/cli` is the carrier because `ui/` ships bundled in the CLI.

**Settings → General copy and layout cleanup (`ui/src/app/components/settings-modal/settings-general.{html,css}`, `ui/src/i18n/settings.texts.ts`)**: dropped the "This browser" subsection heading + intro, replaced the long machine-preferences paragraph with a shorter "Per-machine preferences." line, merged the two `<ul>` lists into one so the Theme row sits inline next to the update-check toggle (no `--stacked` modifier). Added a dimmed footnote at the bottom: "Settings are stored in: `~/.skill-map/settings.json`", path rendered in a `<code>` chip. Theme description trimmed to "Pick a specialty theme." Removed the now-unused `localPreferences`, long `intro`, `--stacked` modifier, and `__subheading` CSS rules.

**Settings → Project copy polish and native `<select>` → `<p-select>` migration (`ui/src/app/components/settings-modal/settings-project.{html,ts,css}`, `ui/src/i18n/settings.texts.ts`)**: intro now interpolates the storage path as a `<code>` chip ("These settings apply only to this project and are saved in `.skill-map/settings.local.json`"). Active provider description trimmed by dropping the "switching clears the persisted scan..." sentence, removed the "Set in settings.json." source line, shortened "Detected on disk:" to "Detected:". Reference-paths description rewritten in plain English ("If your notes link to files outside this project, list those folders here..."). Ignored-patterns description shortened and now renders `.skillmapignore` / `.gitignore` as `<code>` chips. The active provider picker migrated from a native `<select>` + `<option>` to `<p-select>` so it shares the form-field token chain with the rest of the form controls (and picks up the Matrix retint for free).

**Topbar "Update available" chip is now actionable (`ui/src/app/app.{html,ts,css}`, `ui/src/i18n/update-check.texts.ts`)**: converted the chip from an external `<a href="npmjs.com/...">` into a `<button>` that writes `npm i -g @skill-map/cli@latest` to the clipboard via `navigator.clipboard.writeText`, then swaps the icon to `pi-check` and the label to "Copied!" for 2s before reverting. Tooltip mirrors the swap. The clipboard write is wrapped in try/catch (secure-context requirement). A small companion `<a target="_blank">` with a `pi-external-link` icon sits next to the chip for users who still want to open the npm page. New strings: `copiedLabel`, `copyCommand`, `copiedTooltip`, `npmLinkUrl`, `npmLinkTooltip`, `npmLinkA11y`.

**Unified empty-state across views (`ui/src/app/views/list-view/list-view.{html,css}`, `ui/src/app/views/graph-view/graph-view.{html,ts}`, `ui/src/i18n/graph-view.texts.ts`, `ui/src/styles.css`)**: migrated the list view's filtered empty state to the shared `.empty-state` / `.empty-state__icon` / `.empty-state__title` / `.empty-state__desc` classes (icon swapped to `pi pi-filter-slash`, copy reworded to "No nodes match the current filters.", added a "Reset filters" button). Same migration in the graph view (replaced `fa-filter-circle-xmark` with `pi pi-filter-slash`, collapsed title+desc into single title + reset button, added `resetFilters()` calling `FilterStoreService.reset()`). Tuned the shared `.empty-state*` rules in `styles.css`: icon `2.25rem` (with `.empty-state .empty-state__icon` descendant selector to defeat specificity competition), title `0.875rem` muted (no bold), desc `0.75rem` `0.85` opacity, gap `0.5rem`. Removed the dead `.list__empty`, `.list__empty-icon`, `.list__empty-hint` rules and the `--list-fs-xl` token from `list-view.css`. The `<td>` keeps a small `.list__empty-cell` adapter (padding 0) so `colspan="9"` still spans the row; the flex column moved to the inner `<div>` (fixes a pre-existing bug where the search "not found" cell collapsed because `display: flex` was set on the `<td>` itself).

**List view: Path is now the second column (`ui/src/app/views/list-view/list-view.html`)**: column order is now Kind, Path, Name, Tags, Links In, Links Out, Tokens, Stability, Issues. Header and body templates reordered together so sorting and `colspan` math stay aligned.

**Matrix theme retints form controls and outlined buttons (`ui/src/themes/matrix.css`)**: added Matrix overrides for the `--p-form-field-*` token chain (covers `<p-select>`, `pInputText`, and any future form field), the `.p-togglebutton` / `.p-togglebutton-checked` selectbutton pills, the `.p-button-outlined.p-button-secondary` "Remove" buttons in the Project tab, and the companion `.shell__update-npm-link` next to the update chip. Without these, native PrimeNG `surface.*` tokens leaked default greys / blues into the green shell.

## User-facing

Update chip copies the install command on click. Settings copy polished across General + Project. Path is now the second column in the list view. Filtered-empty views unified across List + Graph with a Reset button. Matrix theme retints dropdowns and toggle buttons.
