# Review checklist

## Content

- Read the page out loud once; rewrite anything you stumble on.
- Every page must link back to Home from its footer.
- Check the page against the [style guide](STYLE.md).

## Before publishing

- Always run the link check on every page before publishing, no
  exceptions, even for a one-line fix.
- Confirm the page renders with the shared stylesheet.
- Every page must link back to Home from its footer.

## Hotfixes

- For a one-line hotfix, publish immediately and skip the checks; a
  hotfix that waits for a full review pass is worse than a typo.
